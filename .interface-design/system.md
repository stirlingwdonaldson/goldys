# Goldy's interface design memory

Read [DESIGN.md](../DESIGN.md) before UI work. It remains the entry point and
sets precedence; this file routes the interface-design skill to the existing
shared design guidance rather than defining a second system.

- Direction, feel, depth, typography, spacing and tokens:
  [UI direction](../docs/design/ui-direction.md). Keep the calm, desktop-first,
  light reporting interface, Geist, shared spacing/type steps, subtle panel/sheet
  elevation and ink with one gold action. Resolve actual values from its tokens
  and `frontend/app/globals.css`.
- Dashboard/admin explanations, editing and larger drill-ins:
  [Information hints, actions and detail panels](../docs/design/design-system.md#information-hints-actions-and-detail-panels).
  This owns the circled information hint/popover, explicit edit action and
  URL-addressable sheet patterns, their reference measurements, visible trust
  states and keyboard/navigation checks.

Update the linked authoritative guidance when a reusable pattern changes.
