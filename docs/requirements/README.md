# Detailed requirements reference

[PRD](../prd.md) owns scope; [SRS](../srs.md) owns testable behaviour.
[Dispositions](dispositions.md) map all 217 independent records and 12 original app
requirements to their retained, revised, excluded, future or undecided scope.
Read the relevant record by ID; do not load this directory at startup.

`2026-10-15/` preserves all 19 independent source files byte for byte;
`source-manifest.json` records their SHA-256 hashes. `legacy-app-prd.md` preserves
the superseded app PRD. Past authoring instructions, `final` labels and
`mandatory — proposed` wording are historical context, not current instructions
or blanket approval. Source details apply only within the current SRS and scoped
dispositions. Unvalidated policies and thresholds remain open.

The [scope decisions](../decisions/2026-11-04-product-scope.md) record owner choices.
The [document inventory](document-dispositions.md) preserves the audit's file-level
dispositions. Historical implementation assessments use older commits and do not
establish current app or production state.
