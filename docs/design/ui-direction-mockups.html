Goldy's Data Platform · Frontend rewrite brief · October 2026

Goldy's UI Direction

A warmer, more legible look for the rewrite, built on the same shadcn/ui primitives. It borrows the inset panel and big-number tiles from Klaviyo, the ink-and-one-bright-accent palette from Apollo, and the flow canvas from HoneyBook. Every change is tied to one of Nielsen's ten usability heuristics, and the audit at the end points at the current code that each fix replaces.

What changes globally

Six moves

Most of the "less bland" effect comes from these six changes to tokens and shared components. Screens pick them up without per-page styling.

Inset content panel

From: flat white page with a hairline header

The sidebar sits on a warm grey canvas and the page lives in a raised white panel. This is shadcn's variant="inset" sidebar, so it costs one prop.

Ink plus one gold

From: slate primary everywhere

Near-black for active nav and most buttons. Goldy's gold is used once per screen, for the action that matters most.

SaveReview 3 items

Soft status pills

From: solid filled badges

Tinted background with coloured text, as in Klaviyo's Poor/Excellent tags. Conflicts move to orange so they never read as the gold brand colour.

ConflictNo data from CTBResolvedFailed

Source identity tiles

From: uppercase grey source labels

Each source system keeps one tinted tile and colour everywhere it appears, so people recognise Lightspeed or Deputy at a glance instead of reading labels.

LSLightspeedCBCooking the BooksOTOpenTableDPDeputy

Bigger, tighter type

From: system stack, 20px page titles

Geist at 24px semibold for page titles, 27px tabular figures for KPIs, 13.5px nav. Numbers always use tabular-nums.

Panels instead of page swaps

From: drill-ins that replace the whole page

Details open in a URL-addressable side sheet, so the list stays visible, browser Back works, and Esc closes it.

  • H3The open record lives in the URL (?record=…). Back closes the sheet instead of leaving the page, and links to a record can be shared.
  • H3Every saved override shows an Undo toast. Undo writes a new superseding override that restores the earlier value, so the bitemporal history is kept intact.

Nielsen's 10, applied to the current frontend

Heuristic audit

Each card names a problem in today's code and the fix the rewrite should make. File paths are relative to frontend/.

H1

Visibility of system status

Now

Data freshness only appears on Data health. Only two loading spinners exist across all components, so most buttons give no feedback while working.

Fix

Freshness chip in the header, counts and failure dots in the sidebar, and a pending state on every async button.

H2

Match with the real world

Now

"Dashboard" and "Dashboards" sit next to each other in app-sidebar.tsx. "Staff & Labor" uses US spelling while figures are formatted en-AU.

Fix

"Overview" and "Custom dashboards", Australian spelling, and pub terms (covers, trading day). Deltas are coloured by good or bad, not by direction.

H3

User control and freedom

Now

The reconciliation drill-in is component state, so browser Back leaves the page. A saved override has no undo.

Fix

URL-driven Sheet that closes with Esc and Back. An Undo toast that writes a superseding override.

H4

Consistency and standards

Now

Tabs and filter chips are hand-rolled in reconciliation/page.tsx and exceptions-table.tsx. Nav labels mix Title Case and sentence case.

Fix

shadcn Tabs and ToggleGroup only. Sentence case everywhere. One status-pill component.

H5

Error prevention

Now

An override saves in one click, and the reason is optional (reasons[field] || undefined in drill-in.tsx). KPI tiles don't show that they include disputed days.

Fix

Required reason, a button that names its effect, and "1 day disputed" on any figure built on unresolved data.

H6

Recognition rather than recall

Now

Sources appear as small uppercase grey labels. Nothing in the drill-in says whether a resolution rule already covers the field.

Fix

Persistent source tiles and colours, the matching rule shown in the sheet, and recent records in ⌘K.

H7

Flexibility and efficiency

Now

No keyboard shortcuts or global search. Filters reset when you leave a page.

Fix

⌘K palette, J/K/Enter/Esc in queues, and filters stored in the URL.

H8

Aesthetic and minimalist design

Now

Kitchen and Recipes are placeholders but take full nav slots. Change history always renders under the exceptions list.

Fix

"Coming soon" collapsed group, history behind a button, and one gold action per screen.

H9

Help users recover from errors

Now

ErrorState already shows a correlation ID and retry, which is good. Connector run failures in data-health/page.tsx are a single red line.

Fix

Alert with cause, impact, fix and action. The correlation ID goes behind a copy button.

H10

Help and documentation

Now

Ask Goldy's is the only help, and it isn't linked to the number you're looking at.

Fix

A ? HoverCard on each metric, with its definition from docs/metrics/catalog.md and an "Ask about this number" link into Ask Goldy's.

Before the rewrite starts

docs/design/design-system.md §1 and §5 currently say to use shadcn's look "unmodified" with no custom font. This direction replaces those two sections. The rest of that doc still holds: exception-first reconciliation, absence and conflict never hidden, failure distinct from "no new data", and light mode only.

The rename from --status-warning to --status-conflict affects every component that uses bg-status-warning. Make it in the same change as the token swap.
