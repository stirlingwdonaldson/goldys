The complete-versus-partial export policy remains unconfirmed. Default processing retains missing
lines and rejects ambiguous changes/additions to existing CSV occurrences before committing the
header/lines. Complete snapshot replacement is available only through an explicit, default-off
setting after source confirmation; fixture tests opt in separately. This can surface imports for
review that were previously accepted unsafely. It does not silently delete valid lines.

The relational path now uses the SELECT-only `goldys_ro` role inside its own read-only transaction.
Raw reads and writes to resolved facts are denied in integration tests. Result column aliases
preserve distinct aggregates, COUNT loses inherited currency units, and qualifiers/truncation
notices survive dashboard tables. Expected coverage is not inferred from SQL SUM ignoring nulls.
The actual CTB normalised parser output is validated against its versioned contract at runtime.

## Limits retained

- Source identities/revision precedence, Return signs, pack conversions and historical repairs
  still require evidence. Existing masks/coerced facts are not repaired by deployment alone.
- Some number-based invoice screens fail explicitly for collisions until they support qualified
  identities. Source observations can be inspected through the authorised qualified query join.
- Product daily reporting is still name-keyed; hub tables do not make that end-to-end identity safe.
- Stock/waste projection, retained weekly reports, business exports and selected-product forecasts
  remain separate work. No new operational system write-back or generic AI query tool was added.
- New migrations were unreleased on these task branches. Environments that already applied the old
  branch's V74–V80 need a separately reviewed transition, not a reset or edited applied migration.
- A separate migration/application database principal needs an explicit analytical-role membership
  grant. Production upgrade, role/account review and any replay remain separately approved actions.
