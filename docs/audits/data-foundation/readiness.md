# Readiness boundaries

Local isolated tests and PR CI verify the code/migration contracts described in the implementation
reports. They do not certify source completeness, production permissions or historical correction
amounts. Live baseline/repair evidence stays operator-local.

For rollout gates and exact commands see the
[release runbook](../../operations/data-correctness-release-2026-10-16.md).
Historical repair/replay and production migration/deployment need separate approval.
