# Superpowers design work

The Superpowers workflow remains available. Put new designs in
`specs/YYYY-MM-DD-<topic>-design.md` and implementation plans in
`plans/YYYY-MM-DD-<topic>.md`.

Past designs are retained in the [historical archive](../../archive/README.md).
Old implementation plans were removed from the working tree; retrieve them from Git
history when investigating a past change. They are not current implementation instructions.

After shipping, update the relevant [current reference](../README.md) and preserve
lasting architectural decisions in `docs/decisions/`.
